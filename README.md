# Запись на приём к специалисту

Вариант 3. Python, FastAPI, PostgreSQL. Для запуска нужны Docker Desktop и Python 3.
Команды выполняются из папки проекта. Скрипт испытаний рассчитан на macOS.

## Запуск

```sh
docker compose up -d --build --wait
```

Открыть http://localhost:8083. Логин `demo`, пароль `demo12345`.
При первом запуске создаётся малое наполнение. Повторный запуск сохраняет данные.

## Нагрузка

Подготовить k6 и py-spy:

```sh
python3 load/run.py prepare
```

Смешанный профиль и отдельно сводка:

```sh
./load.sh 2
./load.sh heavy 1
```

Число в конце — запросы в секунду. Ступень длится 30 с, длительность можно
изменить: `./load.sh 2 --seconds 30`. Перед каждой ступенью база приложения
пересоздаётся на рабочем наборе: 200 специалистов, 30 услуг, 200000 слотов,
60000 записей. Вручную добавленные записи удаляются.

Профиль сводки при 2 запросах/с:

```sh
python3 load/run.py profile heavy 2
```

Опыт с двумя процессами и возврат исходной настройки:

```sh
./workers.sh 2
./load.sh 64
./load.sh heavy 4
./workers.sh reset
```

Результаты сохраняются в `results/load/`. В Git они не включаются.
Порог: p95 < 500 мс и ошибки < 1%. `threshold_pass: false` означает, что
ступень не прошла порог.

## Остановка

```sh
docker compose stop
```
